# AI Work System

Interactive, deterministic MOOC for learning how to design human+AI workflows.

**Core idea:** the course teaches the method; learners use their own AI outside the course. There are no AI calls in the learning runtime.

## MVP

Module 01 — **Cambiar el modelo mental**

- visual course map
- deterministic decision scenario
- consequence-based feedback
- external mission using the learner's own AI
- local progress
- GitHub Pages deployment
